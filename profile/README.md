## CU CoSiNe Lab

**Communications, Signal Processing & Networking** at Clarkson University, Potsdam, NY.

We use machine learning and signal processing in a variety of applications, including biometrics, localization and STEM education. This organization hosts the code and data that accompany our papers.

### Research areas

- **PPG signals:** analysis and uses of photoplethysmography from multiple sensors
- **Rural Emergency Medical Services:** AI/ML on EMS data, including fluid detection in ultrasound images
- **Ordinal UNLOC:** indoor localization from pairwise distance comparisons
- **Behavioral biometrics:** identifying users from fine-grained application usage
- **Low-light imaging:** LUX-LID, a lux-annotated low-light image dataset
- **STEM education:** the Reflections echolocation app and workshops

### Repositories

Each paper gets its own repository, created from [paper-template](https://github.com/cu-cosine-lab/paper-template), with the paper citation, a link to the dataset, and instructions to reproduce the results.
